# 스타일 3종 상세

`spec.json`의 `style` 값. 실제 수치는 `scripts/build_teaser.py`의 `STYLES` 딕셔너리에 있다.

## ① `cinematic` — 시네마틱 미스터리 (기본값)

**어울리는 소재**: 사연, 임사체험, 실화 괴담

- 폰트: Noto Serif CJK KR (명조) Bold
- 자막색 `#f2ede4` (미색) / 강조색 `#e85555` (핏빛 붉은색)
- 비네트 있음, 그레인 0.06 (은은함)
- 엔드카드 배경 `#060608` (거의 검정)
- 켄 번즈 줌은 샷마다 방향 교차 (인→아웃→인→아웃)

**연출 원칙**: 조용히 시작해 긴장을 쌓다가 마지막에 뚝 끊는다.
소리도 같은 곡선 — 드론이 서서히 부풀고 심장박동이 빨라지다 임팩트로 종료.

## ② `scroll` — 야담 두루마리

**어울리는 소재**: 전설, 옛날 이야기, 민담

- 폰트: Noto Serif CJK KR (명조) Bold
- 자막색 `#f7f0dd` (한지색) / 강조색 `#c0392b` (낙관 도장 붉은색)
- 비네트 있음, 그레인 0.11 (낡은 종이 질감, 강함)
- 엔드카드 배경 `#1a140c` (짙은 갈색)

**추가로 손볼 것**: 이 스타일은 세피아 톤이 핵심인데 생성기가 자동으로
색보정을 넣지는 않는다. 필요하면 렌더 후 ffmpeg로 입힌다:

```bash
ffmpeg -i in.mp4 -vf "colorbalance=rs=.1:gs=.05:bs=-.1,eq=saturation=0.7" out.mp4
```

## ③ `punchy` — 킬러 쇼츠 훅

**어울리는 소재**: 알고리즘 노출 최우선일 때

- 폰트: Noto Sans CJK KR (고딕) Black(900)
- 자막색 `#ffffff` / 강조색 `#ffd400` (노랑)
- 비네트 **없음**, 그레인 0.03 (거의 없음)
- 엔드카드 배경 순수 검정

**주의**: 톤이 가볍기 때문에 진지한 사연에는 안 맞는다.
클릭률은 높지만 채널 정체성이 흐려질 수 있으니 남발하지 말 것.

**추가 권장**: 이 스타일은 컷이 빨라야 산다. `spec.json`에서
샷 길이를 2.2~2.6초로 줄이고 전체 8~10초로 짜는 게 좋다.

## 검사에서 걸리기 쉬운 것

- **자막 대비 3:1 미달** → 강조색을 더 밝게. `#e24949`는 미달, `#e85555`는 통과.
- **`gsap_exit_missing_hard_kill`** → 페이드아웃 뒤에 `tl.set(...)` 하드 킬 필요.
  생성기가 이미 넣지만, 수동으로 타임라인을 고쳤다면 직접 챙길 것.
- **`text_occluded`** → 자막 트랙(z-index 60)이 비네트(40)보다 위여야 한다.
