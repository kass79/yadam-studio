# 편집 템플릿

> **상태: 초안** — 참고 영상(https://youtu.be/Y0b-fqge9mI)을 아직 프레임 분석하지 못해,
> 한국 유튜브 튜토리얼/브이로그 편집의 일반적인 문법으로 채워둔 기본값이다.
> 참고 영상을 `/watch`로 분석하는 즉시 이 파일 전체를 실측값으로 교체할 것.
> 교체 후 상단을 `상태: 확정 (참고 영상 분석 완료)`로 바꾼다.

## 1. 레이아웃

- **기본 화면**: 화면 녹화가 전체 화면(1920×1080).
- **얼굴 화면(PiP)**: 우하단. 크기는 전체 폭의 22%, 모서리 둥글게(radius 16px),
  흰색 2px 테두리, 화면 가장자리에서 32px 띄움.
- **얼굴 강조 구간**(인트로, 아웃트로, 리액션): 얼굴 촬영을 전체 화면으로 전환,
  화면 녹화는 숨김.

## 2. 자막

- **위치**: 하단 중앙, 화면 아래에서 8% 위.
- **폰트**: 굵은 고딕 계열 (Pretendard Bold 또는 유사).
- **크기**: 화면 높이의 6%.
- **기본 색**: 흰색 + 검정 외곽선(두께 4px) 또는 반투명 검정 배경 박스.
- **강조 단어**: 문장당 핵심 단어 1-2개를 **노란색(#FFD400)** 으로. 숫자·금액은 **초록(#3DDC84)**.
- **등장 효과**: 문장 단위로 갈아끼우기(cut). 강조 단어는 등장 시 1.0→1.15→1.0 스케일 팝(0.25초).
- **표시 단위**: 한 번에 한 문장(최대 2줄). 말 속도에 맞춰 타임스탬프 동기화.

## 3. 화면 효과

- **줌인(punch-in)**: 강조 포인트에서 화면 녹화를 1.0→1.3배 확대(0.4초 ease-out),
  대상 영역 중심으로. 3-5초 유지 후 원래대로.
- **클릭/커서 강조**: 마우스 클릭 지점에 원형 하이라이트(노랑, 0.3초 페이드).
- **박스 강조**: 설명 중인 UI 영역에 빨간(#FF4B4B) 2px 사각 테두리, 등장 시 그리기 애니메이션.

## 4. 전환

- **기본**: 컷 (효과 없음).
- **주제가 바뀔 때**: 0.3초 크로스페이드 또는 좌→우 슬라이드.
- **인트로→본문**: 타이틀 카드(검정 배경 + 흰 제목, 페이드인 0.5초) 2초 노출 후 본문.

## 5. 페이싱

- 무음·머뭇거림 구간은 잘라낸다 (0.5초 이상 침묵 컷).
- 강조 문장 직전에 0.2초 여백을 줘서 리듬을 만든다.

## 6. 오디오

- 얼굴 촬영의 음성을 마스터로. 라우드니스 -14 LUFS 목표.
- 배경음악: 인트로/아웃트로에만, 본문에서는 음성 대비 -18dB 이하로 깔거나 생략.

## 7. 인트로 / 아웃트로

- **인트로** (≤5초): 타이틀 카드 → 얼굴 전체 화면 인사 → 본문.
- **아웃트로** (≤5초): 얼굴 전체 화면 마무리 멘트 + 구독 유도 자막.
