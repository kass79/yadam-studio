# 교육영상 작업 인수인계 (2026-08-22)

이 문서는 「슬기로운 승무생활 교육영상」 전용 세션이 처음 열렸을 때 읽을 요약이다.

## 무엇이 만들어져 있나

`.claude/skills/edu-video/` 한 벌이면 공문 사진 → 교육영상 MP4가 나온다.

| 파일 | 역할 |
|---|---|
| `SKILL.md` | 작업 절차 전체 (이걸 먼저 읽는다) |
| `scripts/build_edu.py` | 카드형 슬라이드 HTML 생성 (title/text/rules/steps/end) |
| `scripts/make_edu_bgm.py` | 배경음악 — 구간(bookend)·분위기(mood) 선택 |
| `scripts/make_edu_sfx.py` | 효과음 — 전환음·항목음·마무리 차임 |
| `scripts/_instruments.py` | 클래식 기타·피아노 음색 합성 |

나레이션은 story-teaser 스킬의 `make_voice.py`를 함께 쓴다 (edge-tts, 프록시 인증서 필요).

## 첫 결과물 (검증 완료)

「운전정보 2026-14 — 건대입구역 외선 PSD 일부 미개방」 사고사례 교육, 90초 / 5MB.
슬라이드 8장 + 남성 나레이션 8문장. 카스가 "잘 만들었다"고 확인함.

## 카스가 준 피드백 (다음에도 지킬 것)

1. **잡음 금지** — 노이즈 성분을 배경음에 넣지 말 것. 화음으로 질감을 만든다.
2. **음악은 일부 구간만** — 설명 중에는 나레이션만. 도입부·마무리에만 음악.
3. **약어는 띄어서** — 나레이션 원고에 `HMI → 에이치 엠 아이`. 붙이면 TTS가 뭉갠다.
4. **악기 소리 선호** — 사인파 패드보다 클래식 기타/피아노를 좋아함.
   마지막 상태: 기타(`guitar`)와 피아노(`piano`) 샘플을 들려주고 고르는 중이었다.
   → **새 세션에서 가장 먼저 할 일: 어느 쪽이 좋은지 물어보고 그 음악으로 확정.**

## 앱 연동 (슬기로운 승무생활)

- 앱에 **교육영상 카테고리가 이미 있고**, 관리자 글쓰기에서 mp4 첨부 → 상세에서 재생된다.
  즉 **앱을 고치지 않아도 오늘부터 쓸 수 있다** (1단계).
- 게시물 "확인 현황" 기능(확인한 사람 명단 + 엑셀/PDF 내보내기)이 이미 있어
  교육 이수 관리에 그대로 쓸 수 있다.
- **2단계(다른 관리자도 앱에서 직접 요청)** 가 다음 목표다. 구조:
  앱에 제작요청 등록 → 이 세션이 예약작업으로 요청함 확인 → 영상 생성 →
  Firebase에 업로드 → 교육영상 게시물 자동 등록.
  서비스 계정 키 설정이 필요하므로 카스와 상의 후 진행할 것.
- 앱 저장소: `kass79/SinjeongSafety` (읽기는 자유, 쓰기는 add_repo로 권한 필요).
  앱의 `CLAUDE.md`에 빌드·배포 규칙이 있으니 앱을 고칠 일이 생기면 반드시 먼저 읽을 것.

## 긴 영상 주의

5분 넘는 영상은 파일이 커져 직원 데이터를 많이 쓴다.
1~3분은 mp4 첨부, 그보다 길면 유튜브(일부공개) 링크 첨부를 권할 것.
