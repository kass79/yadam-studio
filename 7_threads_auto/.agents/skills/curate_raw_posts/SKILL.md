# 🌀 X(Twitter) Raw 포스팅 정제 및 명품 가공 스킬 (curate-raw-posts)

이 스킬은 Apify 스크래퍼가 소셜 네트워크 상에서 성공적으로 긁어온 원본 마크다운 파일들을 분석하여, 한국 독자들에게 가장 매력적인 고부가가치 큐레이션 콘텐츠로 재탄생시키기 위한 **에이전트 자율 가동 워크플로우**입니다. 에이전트(너)는 하드코딩된 스크립트에 의존하지 않고, 스스로의 지능과 아래의 도구들을 활용하여 직접 번역하고 요약 초안을 작성해야 합니다.

---

## 1. 사용 가능한 도우미 및 에셋 (Skill Toolbelt)

스킬 디렉토리(`.agents/skills/create_raw_posts/`) 내에 다음의 리소스들이 준비되어 있습니다. 큐레이션 작업 시 이들을 적극적으로 활용하세요.

1. **딥리딩 도우미 (`scripts/fetch_url.js`)**
   - 역할: 외부 기사 URL의 본문 텍스트를 크롤링하여 최대 3000자 텍스트로 반환.
   - 사용법: `node .agents/skills/create_raw_posts/scripts/fetch_url.js <URL>`
2. **포맷 검증기 (`scripts/verify_format.js`)**
   - 역할: 네가 작성 완료한 마크다운 파일이 절대 제약 규칙(`**` 금지, 해시태그 금지, 하단 URL 양식)을 지켰는지 검증.
   - 사용법: `node .agents/skills/create_raw_posts/scripts/verify_format.js <생성된_마크다운_경로>`
3. **톤앤매너 템플릿 (`assets/templates.md`)**
   - 역할: 트위터(X) 초안 작성 시 적용할 4가지 화법(실무 인사이트형, 트렌드 분석형 등) 예시 제공.
4. **품질 가이드라인 (`references/guidelines.md`)**
   - 역할: AI Slop 배제, 다정한 반말 톤 유지, 은어 사용 규칙 등 에이전트의 작문 기준 제공.

---

## 2. 작업 대상 (Target Files)

* **파일 검색 경로**: `output/{YYMMDD_시간}/` 디렉토리 하위
* **입력 파일 (읽기 대상)**:
  - `twitter_influencer_raw_{YYMMDD_시간}.md`
  - `twitter_raw_{YYMMDD_시간}.md`
* **출력 파일 (작성 대상)**:
  - `twitter_influencer_{YYMMDD_시간}.md`
  - `twitter_{YYMMDD_시간}.md` (파일명에 `_raw`가 포함되지 않아야 함)

---

## 3. 에이전트 자율 실행 파이프라인 (Execution Workflow)

에이전트(너)는 이 스킬을 호출받으면 아래 **4단계(STEP)**를 거쳐 완벽한 결과물을 스스로 생성해 내야 합니다.

### [STEP 1] Raw 데이터 로드 및 분석
1. 타겟 폴더 내의 `_raw_` 파일들(인플루언서 및 일반 트렌드)을 **하나도 빠짐없이 모두** 읽어들여야 합니다. (개수가 많다고 해서 에이전트 임의로 특정 파일의 가공을 건너뛰거나 생략하는 행위는 절대 금지됩니다.)
2. 개별 포스트마다 작성자(@username), 반응 지표(좋아요, 댓글수), 원본 URL, 영문 본문을 정확히 파악합니다.

### [STEP 2] 외부 기사 딥리딩 (정보 증폭)
1. 영문 본문 안에 기사, 깃허브, 블로그 등의 외부 링크가 있다면, 그냥 넘어가지 말고 **반드시 `node scripts/fetch_url.js <URL>` 명령을 실행**하여 기사 원문을 확보하세요. (단, x.com 자기참조 URL은 제외)
2. 확보한 구체적 스펙, 투자액, 팩트 수치를 메모리에 담아둡니다.

### [STEP 3] 3단계 마크다운 직접 생성 (Curation)
에이전트의 뛰어난 글쓰기 실력을 발휘하여, 각 포스팅을 아래 포맷으로만 깔끔하게 작성합니다.
(`references/guidelines.md`와 `assets/templates.md`를 반드시 준수하세요)

```markdown
## [{포스트 번호}] @{작성자} 포스팅 분석

### 1. 한국어 번역
(직역을 피하고 테크 씬의 은어를 살린, 다정하고 극도로 자연스러운 한국어 의역)

### 2. 핵심 내용 정리
- (번역본과 외부 링크 딥리딩에서 얻은 구체적 데이터를 버무린 인사이트 1)
- (인사이트 2 - 내용이 적을 경우 생략 가능)
- (인사이트 3 - 내용이 적을 경우 생략 가능)

### 3. 트위터(X) 발행 초안 (선택한 템플릿의 안 이름 명시)
(templates.md 중 1개를 골라 후킹하게 작성한 다정한 반말 톤 본문)
(반드시 제약 규칙 준수: ** 기호 금지, 해시태그 금지)
참고 URL : {원본 URL}
```
* 위 과정을 각 포스트 블록마다 반복 적용하여 전체 텍스트를 구성한 후, `twitter_{...}.md` 경로로 저장(`write_to_file`)합니다.

### [STEP 4] 자체 포맷 검증 (Verification)
1. 저장이 완료되면, 터미널 명령 도구를 이용해 **반드시 검증기를 스스로 실행**합니다.
   `node .agents/skills/create_raw_posts/scripts/verify_format.js output/.../생성한파일.md`
2. ❌ 에러가 발생했다면, 즉시 에러 로그를 분석하여 파일을 수정한 뒤 다시 검증기를 돌립니다.
3. ✅ `[검증 통과]`가 출력되면 해당 파일의 큐레이션 작업이 대성공적으로 완료된 것입니다.
